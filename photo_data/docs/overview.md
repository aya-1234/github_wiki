## 2. システム概要

SDカード等に保存されている写真を自動的に取得し、写真のメタデータから撮影日時を取得する。

取得した撮影年月日を基準として、保存先に以下のようなディレクトリ構造を自動生成する。

```text
保存先/
├── 2026/
│   ├── 09/
│   │   ├── 24/
│   │   │   ├── IMG_0001.JPG
│   │   │   └── IMG_0002.JPG
│   │   └── 25/
│   └── 10/
└── 2027/
```

または、ユーザー要求に合わせて以下の形式を基本とする。

```text
保存先/
└── yyyy/
    └── mm/
        └── dd/
```

例：

```text
D:\Photo\
└── 2026\
    └── 09\
        └── 24\
            ├── DSC_0001.JPG
            └── DSC_0002.JPG
```

## 3. 開発目的

本システムは、SDカードに保存された写真を手動で分類する作業を自動化することを目的とする。

### 現状の作業

```text
SDカード
 ↓
写真を確認
 ↓
撮影日を確認
 ↓
保存先を探す
 ↓
フォルダを作成
 ↓
写真をコピー
 ↓
次の写真へ
```

### 本システム導入後

```text
SDカード
 ↓
写真自動取得
 ↓
撮影日時取得
 ↓
yyyy/mm/ddを判定
 ↓
フォルダ自動作成
 ↓
写真コピー
```

---

## 4. 基本方針

### 4.1 コピーを標準モードとする

通常利用では、SDカードの元データを変更しない。

```text
SDカード
   │
   │ COPY
   ↓
保存先
```

コピー処理中に以下を禁止する。

* SDカード内ファイルの削除
* SDカード内ファイルの移動
* SDカード内ファイルの名前変更
* SDカード内ファイルの編集

これをシステム上の基本方針とする。

---

## 5. 移動モード

移動モードではSDカード内の写真を保存先へ移動する。

```text
SDカード
   │
   │ MOVE
   ↓
保存先
```

移動によってSDカード内のデータがなくなる可能性があるため、実行前に確認を行う。

### CUI

```text
WARNING:
Move mode will remove files from the SD card.

Continue? [y/N]:
```

`y` の場合のみ実行する。

`n` の場合は処理を中止する。

### GUI

警告ダイアログを表示する。

```text
警告

移動モードでは、SDカード内の写真が
保存先へ移動され、SDカードから削除されます。

データが失われる可能性があります。

[キャンセル] [移動を実行]
```

---

## 6. 警告表示設定

移動モードの警告を毎回表示するかどうかを設定可能とする。

```text
move_warning = true
```

### true

毎回警告する。

### false

警告を表示せず移動処理を開始する。

ただし、設定を無効にしている場合でも、設定画面等で現在の状態を確認できるようにする。

---

## 7. 入力元・保存先

SDカードの入力元と保存先は`.env`に設定する。

例：

```env
SOURCE_PATH=/Volumes/SDCARD/DCIM
DESTINATION_PATH=/Users/user/Pictures
DEFAULT_MODE=copy
MOVE_WARNING=true
```

Windows例：

```env
SOURCE_PATH=E:\DCIM
DESTINATION_PATH=D:\Pictures
DEFAULT_MODE=copy
MOVE_WARNING=true
```

## 8. CUIモード

CUIではTerminal上ですべての操作を完結させる。

### 初回設定

```bash
photo-organizer init
```

初期設定を行う。

```text
Input source:
> /Volumes/SDCARD/DCIM

Destination:
> /Users/user/Pictures

Default mode:
> copy
```

### 通常実行

```bash
photo-organizer run
```

### コピー

```bash
photo-organizer copy
```

### 移動

```bash
photo-organizer move
```

## 12. 写真日時

基本的には写真のEXIFメタデータに存在する撮影日時を使用する。

優先順位：

```text
EXIF DateTimeOriginal
        ↓
EXIF DateTimeDigitized
        ↓
EXIF DateTime
        ↓
ファイル日時
        ↓
日時取得不能
```

EXIF等から撮影日時を取得できない場合の処理は基本設計で定義する。

---

## 13. 重複ファイル

完全に同一の写真データについては、同一ファイルとして判定する。

ファイル名ではなく、ファイル内容のハッシュ値を利用する。

例：

```text
SHA-256
```

```text
写真A
 ↓
SHA-256
 ↓
abc123...

写真B
 ↓
SHA-256
 ↓
abc123...
```

同じハッシュ値の場合、同一データとして扱う。

---

## 14. 重複時の基本方針

### コピー元と保存先に同一データが存在する場合

保存先へのコピーをスキップする。

```text
Source
IMG001.JPG
    │
    │ SHA-256
    ↓
ABC123

Destination
IMG001.JPG
    │
    │ SHA-256
    ↓
ABC123

→ 同一ファイル
→ コピーをスキップ
```

### 重要

コピー・移動モードを問わず、**重複判定を理由として元データを勝手に削除しない**ことを基本仕様とする。

特にコピーの場合、SDカードのデータを変更してはならない。
