# 実装計画 1：写真自動整理ツール初回実装

## 1. 変更対象

`pyproject.toml`、`src/photo_organizer/`、`tests/`、`README.md`、`.env.example`、配布設定、および `docs/tasks_1.md`。

## 2. 実装内容

1. 設定とPhoto/ProcessResultモデルを用意する。
2. 再帰スキャナー、EXIF/mtime日時取得、日付保存先、SHA-256重複判定、衝突回避を実装する。
3. コピーと移動の安全性を実装し、Organizerでファイル単位のエラー継続と結果集計を行う。
4. `init`、`run`、`copy`、`move`、`status`を提供するCUIを実装する。
5. PySide6を使い、設定・開始・キャンセル・進捗表示を持つGUIをCoreから分離して実装する。
6. OS起動補助、ログ、PyInstaller配布定義、利用手順を追加する。
7. 単体・結合・データ保護テストを追加し、タスク台帳を実績に合わせて更新する。

## 3. 影響範囲

新規Pythonパッケージとテスト、既存の雛形エントリーポイント、プロジェクト依存定義および利用ドキュメント。

## 4. リスク

- EXIFを含まない画像では更新日時が整理日として使われる。設定でスキップへ変更できるようにする。
- HEIC/HEIFの読み取りはPillow環境で対応できない場合があるため、読み取り不能時は設定に従うフォールバックとする。
- 移動はコピー先の書き込みとサイズ・ハッシュ確認後にのみ元を削除する。重複スキップでは元を削除しない。
- GUIとPyInstallerはOS固有のビルド検証を各OS上で行う必要がある。

## 5. テスト方針

一時ディレクトリと小さな画像 fixture を利用して、スキャン、日時fallback、重複、衝突、コピー・移動、キャンセル、安全性、Organizer集計を自動確認する。静的確認とCLIヘルプ起動も行う。
