# Ubuntu 26.04 Server 導入Q&A 作成計画

## 1. 要件整理

| 項目 | 内容 |
|---|---|
| 実現したい内容 | Ubuntu 26.04 Serverへの導入判断、初期設定、定期実行、障害対応に利用できるQ&Aを作成する |
| 現状 | Ubuntu 24.04を前提としたセットアップガイドとcron実行スクリプトがあるが、導入判断に必要な情報がQ&A形式でまとまっていない |
| 制約条件 | 初回認証はGUI操作が必要。Microsoftのパスワード、PIN、MFAは自動操作しない。既存のアプリ動作や設定仕様は変更しない |
| 成功条件 | 管理者が前提条件、導入手順、安全上の注意、運用方法、代表的な障害対応をQ&Aから確認できる |

## 2. 調査結果

- Ubuntu 26.04.1 LTSのServerイメージはGUIを標準搭載しない。
- Ubuntu 26.04.1 LTSの標準Pythonは3.14系であり、本アプリの`Python >= 3.10`という宣言範囲内である。
- Google Chromeは公式要件上、64bit Ubuntu 18.04以降をサポートする。
- 本アプリは初回およびセッション失効時に、対象サーバー上のChromeで対話的なログインを必要とする。
- cronの実行時刻はOSのタイムゾーンに従う。一方、アプリが処理対象とする「当日」はコード上で日本標準時に固定されている。
- `.env`、Chromeプロファイル、工数JSON、ログは同じ専用ユーザーで管理する必要がある。
- 現在の`.env`は所有者以外も読み取り可能なため、導入時には`chmod 600 .env`の確認が必要である。

## 3. 実装計画

1. **変更対象**
   - `docs/ubuntu_server_qa.md`
   - `README.md`
   - `docs/linux_setup_guide.md`
   - `docs/tasks_2.md`

2. **実装内容**
   - Ubuntu 26.04 Server向けの導入・運用Q&Aを新規作成する。
   - 既存資料のUbuntu 24.04およびPython 3.12表記を26.04／Python 3.14系へ更新する。
   - READMEからQ&Aへの導線を追加する。

3. **影響範囲**
   - 文書のみ。Pythonコード、設定仕様、cron登録内容は変更しない。

4. **リスク**
   - GUIの用意方法はサーバー環境に依存するため、特定方式の動作を保証しない。
   - Python 3.14と実ブラウザを使った動作は対象サーバーでの導入検証が必要である。
   - ChromeやSalesforceの画面変更により、将来手順が変わる可能性がある。

5. **テスト方針**
   - 文書内の相対リンクが存在することを確認する。
   - 設定名、CLIオプション、終了コードを実装と照合する。
   - 全自動テストを実行し、文書変更による非退行を確認する。
